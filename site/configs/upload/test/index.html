How to Get Item JSON

  1. Go to the CSFloat page with the item you want.
  2. Right-click on the item listing and choose Inspect.
  3. Find the HTML element containing data-csfloat-data.
  4. Double-click the value inside that attribute and copy it fully.
  5. Paste the result in the box, this is your item JSON.
