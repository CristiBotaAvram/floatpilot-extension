# FloatPilot ✈️

**Analyze CS2 skin floats and market data in real-time to find profitable flips.**

FloatPilot is a Chrome Extension designed to:
- Scan live CSFloat marketplace listings
- Grab skin names, float values, and prices
- Highlight high-value skins
- Prepare for future profit detection and flipping tools

---

## 🚀 Features

- ✅ Automatic listing detection (even on CSFloat refresh)
- ✅ Highlights skins over customizable price thresholds
- ✅ Clean, fast, and lightweight
- ✅ Written in TypeScript + React + Vite

---

## 🔧 Installation (Development Mode)

1. Clone this repository:
   ```bash
   git clone https://github.com/CristiBotaAvram/floatpilot-extension.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the project:
   ```bash
   npm run build
   ```

4. Open Chrome → `chrome://extensions`
5. Enable **Developer Mode**
6. Click **Load Unpacked**
7. Select the `/dist` folder generated by the build
